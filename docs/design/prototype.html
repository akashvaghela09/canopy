Your first conflict

Teaches reading conflict markers
Recommended first
6.02 Three-way merge

When two branches change the same lines of the same file, git cannot pick a side for you. It stops the merge, writes both versions into the file between markers, and waits.

The block between <<<<<<< HEAD and ======= is the branch you are on. The block between ======= and >>>>>>> feature is the branch you are merging in.

Try it

  1. Merge feature into main. git stops with a conflict in recipe.txt.
  2. Check the status of the repo and find the file listed as "both modified".
  3. Open recipe.txt in the files panel and read the two blocks.
  4. Answer the questions in the lesson panel.
