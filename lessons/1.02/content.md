Now you make things. Four more commands:

- `mkdir project` creates a folder called `project`.
- `touch notes.txt` creates an empty file called `notes.txt`.
- `echo "hello git" > hello.txt` writes the text `hello git` into `hello.txt`. The `>` means "send the output into this file". It replaces whatever the file held before.
- `cat hello.txt` prints what is in the file.

## Try it

1. Read `recipe.txt` and answer the question about it.
2. Create a folder called `project` and move into it.
3. Inside it, create an empty file `notes.txt`, and a file `hello.txt` containing the text `hello git`.
4. Read `hello.txt` back to check.

## What just happened

Everything git tracks is ordinary files in ordinary folders. You can make them with these commands or with the editor in the files panel; git does not care which.
